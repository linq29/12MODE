# 十二支詣 - 干支にまつわる神社探し

本リポジトリは、就職作品プレゼンテーション（2026）で展示した個人制作作品  
**「十二支詣」** のリニュアル版です。

> 十二支を辿りながら、自分と縁のある神社に出会う体験を提供します。

## 概要

神社巡りに興味はあるものの、始め方が分からない人に向けて、  
干支とご利益を軸に神社を探せるWebアプリです。

- 神社探し
- 十二支診断
- バーチャル参拝
- ことわざくじ

HAL東京 進級制作展 2024年度 銀賞受賞。

## 制作背景

### 課題:

- 神社の数が多く、初心者は巡り方の入口を見つけにくい
- 情報サイトは多いが、体験としての導線が弱い

### 解決方針:

- 干支 x ご利益の二重フィルターで「導かれる体験」を設計
- 診断と選択を重ねる構成で能動的な体験を実現

## 技術スタック

- Vite + React（フロントエンド）
- Node.js (HTTP server) + SQLite（バックエンド）
- Photoshop / Illustrator
